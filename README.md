# A Med Spa AI Solution

An interactive browser experience by Emergent AI LLC: inquiry-to-consultation, staff-review routes, follow-up workflow and session reporting.

## Explore

Open `index.html` locally, or use the GitHub Pages site linked in this repository's deployment section.

- **Client experience:** try scripted service questions, clinical escalation and a local consultation-request flow.
- **Follow-up:** step through six stages with consent, staff ownership and scheduling checks.
- **Dashboard:** see counters and activity generated by your own browser-session actions. No client performance figures are supplied.

## What runs

The page runs HTML, CSS and JavaScript entirely in the browser. It has no backend or external dependencies. Chat uses local scripted responses, not a language model. Consultation requests are local session entries, not real appointments. Workflow stages are interactive text, not scheduled messages. Counters reset when the page reloads. No AI, SMS, phone, calendar or patient-record service is connected, and no messages are sent.

Use the test controls only. Do not enter personal or health information. No client deployment, client identity, testimonials or business results are claimed.

## Production requirements

Connecting this experience to a practice requires approved service content, scheduling and messaging integrations, access controls, consent and opt-out handling, privacy and vendor review, secure data handling and named staff escalation. Clinical advice stays with qualified staff. Measurement requires an agreed baseline, data sources and reporting period. Nothing here asserts regulatory compliance or guarantees business outcomes.
